# Portfolio Website

A modern, responsive portfolio single page website built with HTML, CSS, Bootstrap and JavaScript to showcase projects, skills, professional experience, and contact information.

## Overview

This portfolio website provides a clean and accessible way to present my professional profile, featured projects, technical skills, work experience, resume, and social links.

It includes responsive layouts, mobile navigation, project cards and experience.

## Features

- Responsive design for desktop, tablet, and mobile devices
- Mobile navigation menu
- Hero section with introduction and availability status
- About section
- Skills and technologies section
- Why hire me section
- My Working process section
- Featured projects section
- Live demo 
- Hire me section
- Facebook, GitHub, LinkedIn, instagram and email links
- Smooth scrolling navigation
- Modern styling with CSS
- Lucide icons

## Tech Stack

- HTML5
- CSS3
- Bootstrap
- JavaScript
- JQuery
- Organic SEO
